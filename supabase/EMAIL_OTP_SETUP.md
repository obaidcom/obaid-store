# إعداد رمز التحقق بالبريد — متجر بيت ستور

واجهة التسجيل في الفرع `rebuild/clean-store-v2` تستخدم `signUp` ثم تعرض حقل رمز من 6 أرقام، وتتحقق منه عبر `verifyOtp({ email, token, type: "signup" })`. زر إعادة الإرسال يستخدم `auth.resend({ type: "signup", email })`.

## قالب رسالة تأكيد التسجيل

القالب الاحترافي موجود في `supabase/templates/confirmation.html`. انسخ محتواه إلى:

Supabase Dashboard → المشروع `bvhyvznammmfsdhibcea` → Authentication → Email Templates → Confirm signup

- **Subject:** `رمز التحقق من متجر بيت ستور`
- يجب أن يحتوي القالب على `{{ .Token }}` حتى يعرض رمز التحقق، وليس `{{ .ConfirmationURL }}` كرابط تأكيد فقط.
- احفظ القالب واختبر التسجيل باستخدام بريد تملكه.

## اسم المرسل وإعداد SMTP

من إعدادات SMTP في المشروع، اضبط **Sender name** على `متجر بيت ستور`. استخدم عنوان From موثّقًا ومسموحًا به من مزوّد البريد. يلزم إعداد مزوّد SMTP موثوق وبياناته السرية داخل لوحة Supabase؛ تغيير اسم المرسل وحده لا يضمن إرسال البريد.

لا تضع كلمة مرور البريد أو SMTP أو أي مفتاح سري في GitHub أو متغيرات `NEXT_PUBLIC_*`. أدخلها مباشرة في إعدادات SMTP الآمنة داخل لوحة Supabase.

## تنبيه مهم

هذا التعديل يحدّث قالب المشروع في GitHub فقط؛ لا يغيّر القالب المنشور داخل Supabase تلقائيًا، ولا يثبت تسليم البريد إلى صندوق الوارد. بعد لصق القالب وضبط SMTP في لوحة Supabase، اختبر إرسال الرمز وإدخاله وإعادة إرساله، ثم راجع سجلات Auth ومزوّد البريد.
