# إعداد رمز تأكيد البريد — متجر عبيد ستور

واجهة التسجيل في الفرع `rebuild/clean-store-v2` تستخدم `signUp` ثم تعرض حقل رمز من 6 أرقام، وتتحقق منه عبر `verifyOtp({ email, token, type: "signup" })`. زر إعادة الإرسال يستخدم `auth.resend({ type: "signup", email })`.

## قالب رسالة التأكيد

القالب الجاهز موجود في `supabase/templates/confirmation.html`. انسخ محتواه إلى:

Supabase Dashboard → المشروع `bvhyvznammmfsdhibcea` → Authentication → Email Templates → Confirm signup

- Subject: `رمز تأكيد حسابك في متجر عبيد ستور`
- يجب أن يحتوي القالب على `{{ .Token }}`، وليس `{{ .ConfirmationURL }}`، لكي تصل رسالة برمز رقمي بدل رابط.
- احفظ القالب واختبر تسجيل حساب ببريد تملكه.

## اسم المرسل والبريد الصادر

من إعدادات SMTP الخاصة بالمشروع، عيّن اسم المرسل إلى `متجر عبيد ستور`، والبريد المرسل إليه/منه إلى `gomaaobaid4@gmail.com` فقط إذا كان مزوّد البريد يسمح بالإرسال منه وتم التحقق منه. عنوان From وحده لا يفعّل الإرسال؛ يلزم إعداد مزوّد SMTP موثوق ببياناته السرية، وقد يتطلب Gmail كلمة مرور تطبيق أو مزوّد إرسال خارجي.

لا تضع كلمة مرور البريد أو SMTP أو أي مفتاح سري في GitHub أو متغيرات `NEXT_PUBLIC_*`. أدخلها مباشرة في إعدادات SMTP الآمنة داخل لوحة Supabase. لم يتم ادعاء تفعيل SMTP أو وصول رسالة حقيقية قبل إجراء اختبار فعلي.

## ملاحظة تشغيل

تغيير القالب في GitHub وحده لا يغيّر قالب البريد في مشروع Supabase المستضاف؛ يجب حفظه في لوحة Authentication. بعد ضبط القالب وSMTP، اختبر التسجيل وإدخال الرمز وإعادة إرساله، ثم تحقق من أن المستخدم أصبح مؤكد البريد.
