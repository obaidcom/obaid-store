# عبيد ستور — إعادة بناء نظيفة

واجهة جديدة من الصفر على فرع `rebuild/clean-store-v2`. لا تستخدم هذه النسخة قاعدة بيانات أو خدمات دفع أو حسابات حقيقية؛ بيانات المنتجات والأسعار تجريبية داخل الواجهة فقط.

## التقنية
- Next.js App Router وTypeScript
- Tailwind CSS v4 وLucide React
- واجهة عربية RTL متجاوبة للهاتف والكمبيوتر

## التشغيل محلياً
```bash
npm install
npm run dev
```

## فحص البناء
```bash
npm run build
```

## الموجود في هذه المرحلة
- صفحة رئيسية جديدة وهوية بصرية زرقاء متوازنة.
- سلايدر رئيسي مع انعكاس بصري، أقسام مصوّرة، وبطاقات منتجات.
- بحث وتصنيف، مفضلة، وسلة تجريبية مع تعديل الكميات والحذف.
- واجهات توضح أن تسجيل الدخول والدفع وإرسال الطلبات غير مفعّلة.

## حدود مهمة
لم يتم الاتصال بأي قاعدة بيانات أو تعديلها، ولم يتم إعداد مدفوعات حقيقية. لا تدخل بيانات شخصية في هذه النسخة. لا يتم النشر أو الدمج إلى `main` تلقائياً؛ يلزم اختبار البناء ومراجعة التغييرات أولاً.
