# عبيد ستور — متجر إلكتروني عربي

واجهة متجر عربية RTL مبنية باستخدام Next.js وTypeScript وTailwind CSS، مع اتصال فعلي بمشروع Supabase المخصص للمتجر.

## التقنية
- Next.js App Router وTypeScript
- Tailwind CSS v4 وLucide React
- Supabase Auth وPostgres وStorage
- واجهة عربية RTL متجاوبة للهاتف والكمبيوتر

## إعداد الاتصال
أضف متغيرات البيئة التالية إلى Vercel (Development وPreview وProduction):

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` (مفتاح Publishable العام فقط؛ لا تضع service_role في المتصفح)

مشروع Supabase الخاص بالمتجر: `bvhyvznammmfsdhibcea`.

## البيانات والوظائف المتصلة
- كتالوج المنتجات والأقسام والصور والأسعار والمخزون.
- تسجيل الدخول وإنشاء الحساب عبر Supabase Auth.
- الملف الشخصي والعنوان والصورة الشخصية في Storage.
- إنشاء الطلبات في قاعدة البيانات مع حفظ عناصر الطلب والتحقق من السعر والمخزون في الخادم.
- رمز تتبع فريد، واستعلام عن حالة الطلب.
- وسائل الدفع المعروضة: شام كاش، سيريتل كاش، والدفع عند الاستلام.

## حدود يجب معرفتها قبل البيع الفعلي
- المنتجات الثمانية الأولية والصور والأسعار الموجودة هي بيانات تأسيسية؛ راجعها واستبدلها بمنتجاتك وأسعارك ومخزونك الحقيقي قبل استقبال العملاء.
- شام كاش وسيريتل كاش لا ينفذان تحويلاً آلياً؛ يلزم التحقق اليدوي من التحويلات من جهة التاجر.
- لا يوجد حتى الآن تكامل شركة شحن أو لوحة إدارة مكتملة لإدارة المنتجات والطلبات. تحديث حالات الطلبات يحتاج إجراءً إدارياً موثوقاً.
- لا تعتبر نشر المعاينة وحده دليلاً على اكتمال جميع إجراءات التشغيل التجاري.

## التشغيل المحلي
```bash
npm install
npm run dev
```

## فحص البناء
```bash
npm run build
```

يتم العمل على فرع `rebuild/clean-store-v2`؛ لا تُدمج التغييرات في `main` تلقائياً، ولا تُعدّل مستودع تطبيق الصيانة `obaid-app2`.
